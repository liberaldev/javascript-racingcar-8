# javascript-racingcar-precourse
## `App` 클래스
- [x] 입력 기능 추가
- [ ] 입력값을 `,`로 기준자로 한 배열로 만든 다음, 해당 배열을 인자로 하여 `Cars` 클래스를 호출
- [ ] 입력한 횟수만큼 무작위 값을 구하여 무작위 값이 4 이상의 경우 전진하게 하는 경주 로직 구현. 이때 차수별 실행 결과도 출력.
- [ ] `Cars` 클래스의 `sort` 메소드를 이용해 우승자를 선정하는 메소드 구현
- [ ] 우승자 안내 문구 출력
## `Cars` 클래스
- [x] 차 이름들로 이루어진 배열을 인자로 하는 생성자 생성.
- [x] 각 차 이름이 잘 입력되었는지 검증하는 메소드 추가하고 전술한 생성자에서 호출.
- [ ] 각 요소가 자동차 이름을 나타내는 `name` 속성과 전진 수를 나타내는 `steps` 속성(기본값 0)을 가진 객체로 구성된 배열을 `this.cars`에 할당하는 로직을 생성자에 추가.
- [ ] 각 배열을 순회할때 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상의 경우 `steps`의 수를 증가하는 메소드 구현.
- [ ] `steps`의 수를 따라 정렬하는 메소드 구현
- [ ] 얼마나 주행했는지를 출력하는 메소드 구현
